# SRUK Indonesia Project List Scraper

Your original working script for scraping the SRUK (SRN, api.srukindonesia.id
domain) Indonesia mitigation project registry. Provided as-is, unmodified.

## Usage

See the script's own header/comments for exact CLI usage, pagination
parameters, and output layout — it was already working when uploaded to
